Why CKG?

Built for production

Enterprise-grade design decisions that set this platform apart

🔒

Zero-Trust Security

JWT auth with PermissionGuard on every route. API keys are SHA-256 hashed. Audit logs track all actions.

🏗️

Modular Monorepo

3 apps in one repo with shared tooling. Each NestJS module is self-contained with its own DTOs, service, and controller.

⚡

Async Processing

BullMQ-powered job queues for document indexing. Non-blocking API responses with background workers and SSE status.

🔄

LLM Agnostic

Pluggable LLM layer: switch between Ollama (local) and LiteLLM (cloud) with zero code changes. Provider abstraction built-in.

📊

Full Observability

Real-time SSE trace logs, per-project usage tracking, audit trails with actor/action/metadata, and request ID middleware.

🌍

i18n Ready

Dashboard supports Vietnamese and English out of the box. Signal-based language switching with no page reload.

🎨

Premium UI

Dark/light themes with smooth transitions. Skeleton loading states, cascading dropdowns, responsive data tables.

🐳

Docker-Ready

One-command infrastructure setup. PostgreSQL, Redis, Qdrant, Neo4j — all containerized with health checks.
