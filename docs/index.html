Quick Start
# Start infrastructure
docker compose up -d

# Install & migrate
pnpm install
pnpm prisma migrate dev

# Run the platform
pnpm start:dev       # API on :3000
pnpm start:portal    # Portal on :4200

# Index your first document
curl -X POST http://localhost:3000/documents/index \
  -H "Authorization: Bearer kgw_live_..." \
  -d '{"title":"My Doc","content":"...","source":"api"}'

Everything You Need

A complete platform for knowledge management and AI-powered retrieval

🔍

Semantic Search

Vector-based search powered by Qdrant. Find relevant content by meaning, not just keywords. Configurable top-K with relevance scoring.

🤖

RAG Engine

Retrieval-Augmented Generation using Ollama. Ask questions in natural language and get answers grounded in your indexed knowledge.

🏢

Multi-Tenant

Full project isolation with scoped API keys. Each project has its own document space, usage tracking, and audit trail.

🔌

MCP Server

Model Context Protocol support for AI agents. Give Claude, GPT, or any MCP client direct access to your knowledge base.

🎛️

Admin Portal

Angular-based admin dashboard. Manage projects, API keys, documents, monitor jobs, and explore search/RAG playgrounds.

🔐

Dual Authentication

API keys for programmatic access with scopes. JWT tokens for admin portal with role-based access control.

📊

Usage & Audit

Per-request usage tracking with latency metrics. Full audit trail for compliance and debugging.

⚡

Async Indexing

BullMQ job queue for document indexing. Chunk, embed, and store documents asynchronously with job status tracking.

📖

OpenAPI / Swagger

Full OpenAPI 3.0 spec with interactive Swagger UI. Auto-generated from TypeScript decorators for always-accurate docs.
